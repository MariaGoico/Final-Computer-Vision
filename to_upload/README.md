# DeFence

## Training & Data
- fence_segmentation.ipynb: Fence segmentation model development and training.

- train_by_patches.ipynb: Model training using localized image patches experiment.

- denoising_data_augmentation mix.ipynb: Training and creation of our best model.

## Inference Pipelines
- full_pipeline_patches.ipynb: Original full sized images inference with simple patches for fence detection + examples.

- full_pipeline_patches_option_2.ipynb: Alternative mode with a bigger halo and sliding window + examples.

- full_pipeline_patches_both.ipynb: Combined hybrid pipeline + Gradio Interface.

## Evaluation
- comparison.ipynb: Comparision of the best checkpoints obtained from several experiments.
